# Changelog

## v1.0.3

- Combined UNISG headquarters at Jupiter, WALO-native services, faction contracts and scientific escorts: Protocol Contour and Biological Reconnaissance.
- Two-stage Story Mode detection for WALO new-game initialization and ordinary save loading; persistent HQ opt-in and restoration without load-time squad seeding.
- English and Russian text, with the existing fallback localizations retained.
- The author reported successful in-game testing of the combined archive as one mod.

### GitHub release preparation

- Preserved all 37 gameplay files against the original v1.0.3 SHA-256 manifest; no gameplay fixes, refactoring, save-key changes or version bump.
- Updated installation, full-file override warnings, Story/Taskboard limitations, upstream integration and third-party notices.
- Added targeted validation and reproducible, allowlisted MO2 packaging. Documentation and packaging differ from earlier archives; the gameplay payload is unchanged.

Earlier component versions remain documented in `RELEASE_INFO.txt`; this preparation does not reset or reconstruct their independent histories.
